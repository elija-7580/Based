The team

One human.
A night shift.

Based is built by Elija in Vienna, together with the same kind of agents Based will give you. An architect agent plans with him during the day. A night shift picks up the backlog, writes the code, runs the tests and leaves a log by morning. Nothing merges unless the tests are green, and every line is in the public repo.

We use what we build. If an agent workflow is annoying, we notice first.
